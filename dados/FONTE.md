# Fonte dos dados

## Base utilizada

**Medical Appointment No Shows**

Fonte: Kaggle  
Arquivo utilizado no projeto: `KaggleV2-May-2016.csv`

Base disponível em:

https://www.kaggle.com/datasets/joniarroba/noshowappointments

## Uso no projeto

A base foi utilizada no projeto MedPredict para análise de dados históricos de consultas médicas e construção de modelos de Machine Learning voltados à previsão de No-Show.

Durante o desenvolvimento do projeto foram realizadas etapas de análise exploratória, tratamento e limpeza dos dados, seleção de variáveis, preparação dos dados e comparação entre diferentes modelos de classificação.

## Reprodução

Para reproduzir a análise:

1. Acesse a página da base no Kaggle.
2. Faça o download do arquivo original.
3. Utilize o arquivo `KaggleV2-May-2016.csv`.
4. Abra o notebook disponível na pasta `notebook/`.
5. Execute as células na ordem apresentada.

## Observação

O arquivo disponibilizado neste repositório poderá ser uma amostra da base original, utilizada apenas para facilitar a reprodução do projeto.

A fonte completa e original dos dados permanece disponível no Kaggle pelo link informado acima.
